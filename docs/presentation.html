HyperConv3

Datapath: 6-stage MAC pipeline, 1 output/cycle

Pipeline (72-cycle latency)

  1. window registers (N×N)
  2. N² products → DSP48 MREG
  3. product register → DSP48 PREG
  4. partial sums of 3
  5. final sum (20-bit, exact)
  6. saturate / ReLU → s16

Fixed-point (no intermediate overflow)

u8 × s8 → s16 product (−32640…+32385)
3 products → 18 b partial · 3 partials → 20 b accumulator
only the final saturate to s16 loses range — by design

sobel_x @ 100 MHz: first pixel → first result = 72 cycles

HyperConv6

How 2 px/cycle costs zero extra DSPs — dual-multiply packing

  • Adjacent windows share the kernel → two pixels pack into the DSP's 25-bit A port (stride 16) against one shared coefficient: P = w0·c + 2¹⁶·(w1·c); one-bit borrow correction on extraction.
  • Proven standalone: 101,276 vectors, 0 errors, exactly 1 DSP per packed multiply.
  • Alternatives eliminated by measurement/arithmetic: separate-coefficient DMP (18-bit B port), DSP cascade (s19 overflows stride-16 field), multipumping (adds MMCM/CDC, zero gain), 18-DSP 2-px (FoM-neutral).
HyperConv7

Design tradeoffs — measured, not guessed

  • Two-stage adder tree: splitting the 9-input tree into partial-sums-of-3 + final sum raised Fmax 405 → 479 MHz (ZCU106) and reduced LUTs — shallower carry chains pack better.
  • DSP vs LUT multipliers: LUT mult misses 200 MHz on Z-7020 (multiply itself is the critical path). DSP mapping saves ~560 LUTs, absorbs pipeline FFs into MREG/PREG (562→141 FFs), and wins FoM.
  • Baseline vs hybrid: DMP doubles throughput for +117 LUTs, +29 mW and zero extra DSPs → FoM 10.60 → 14.96×10⁻³ (+41%), with more timing slack. Single clock domain, no MMCM/CDC.
  • Distributed RAM line buffers: avoid the 100× BRAM FoM penalty at 32-px rows; natural BRAM mapping beyond ~128 px, no RTL change.
  • Valid-gated pipeline: bubbles hold data (switching power ↓), valid bits free-run — stall tolerance is free.
  • Part choice dominates FoM via static power: same RTL scores 10.6×10⁻³ on Z-7020 vs 2.26×10⁻³ on ZU7EV (0.5 W die leakage).
